# MacroHall

CollegeMacro backend and mobile app.

## Folders

- `CollegeMacro-backend`
- `CollegeMacro-mobile`

## Backend status

The backend was refactored to support scaling across schools using:

- shared normalized schema
- per-school parser adapters
- config-driven URLs/selectors
- school/hall keyed storage
- fixture-based parser tests
